## 📌 About the Project

This project is a personal developer portfolio designed to showcase my
technical skills, projects, AWS cloud knowledge, and software development
experience.

The website is hosted on Amazon S3 and uses GitHub Actions to automatically
deploy new changes to the S3 bucket whenever code is pushed to the `main`
branch.
